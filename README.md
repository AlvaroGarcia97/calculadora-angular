# Calculadora con Angular

Calculadora sencilla desarrollada con Angular 19 y componentes standalone. Permite realizar operaciones bsicas (suma, resta, multiplicacin y divisin).

## Funcionalidades

- Suma, resta, multiplicacin y divisin
- Punto decimal
- Botn limpiar (C)
- Interfaz tipo calculadora

## Tecnologas

- Angular 19
- TypeScript
- CSS

## Instalacin

```bash
# Clonar
git clone https://github.com/AlvaroGarcia97/calculadora-angular.git
cd calculadora-angular

# Instalar dependencias
npm install

# Arrancar
ng serve
```

Abrir http://localhost:4200

## Build

```bash
ng build
``
