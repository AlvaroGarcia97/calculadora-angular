# Calculadora con Angular

Calculadora sencilla desarrollada con Angular 19 y componentes standalone. Permite realizar operaciones básicas (suma, resta, multiplicación y división).

## Funcionalidades

- Suma, resta, multiplicación y división
- Punto decimal
- Botón limpiar (C)
- Interfaz tipo calculadora

## Tecnologías

- Angular 19
- TypeScript
- CSS

## Instalación

```bash
# Clonar
git clone https://github.com/AlvaroGarcia97/calculadora-angular.git
cd calculadora-angular

# Instalar dependencias
npm install

# Arrancar
ng serve
```

Abrir http://localhost:4200

## Build

```bash
ng build
``
